什么是数据库

数据库是长期存储在计算机内、有组织、可共享的数据集合，解决海量数据管理问题。相比 Excel，它能支持上亿条数据、多人同时操作，保证数据不混乱。

数据库的层级结构可以用学校类比：

层级 类比 示例
顶层：数据库 整个学校 school 库
中层：数据表 学校不同部门 users 表、classes 表
底层：字段 + 数据 表头 + 行内容 字段：id、name，数据：2025001、张三

数据库管理系统（DBMS）

DBMS 是数据库的”管家”，负责管理数据访问和存储规则。常见的有：

  • Oracle：功能强、收费，银行和电信行业常用
  • SQL Server：适配 Windows，政府单位常用
  • MySQL（重点）：开源免费、轻量，网站和中小型系统主流选择

数据库连接

Navicat 可视化连接

  1. 打开 Navicat → 左上角「连接」→ 选择「MySQL」
  2. 填写核心信息：
    • 主机：localhost（本地数据库）
    • 端口：3306（MySQL 默认端口）
    • 用户名：root（超级管理员）
    • 密码：安装 MySQL 时设置的密码
  3. 点击「测试连接」，提示”连接成功”即可
  4. 双击连接名，即可查看和操作数据库

命令行连接

  • -u：指定用户名
  • -p：需要输入密码（输入时密码不显示，属正常现象）

PHP 与数据库交互

PHP 操作 MySQL 的核心流程分四步：

步骤 操作 说明
第一步 mysqli_connect(地址, 账号, 密码, 库名) 建立连接
第二步 $_POST['name'] / $_POST['password'] 接收用户输入
第三步 mysqli_query($conn, $sql) 执行 SQL 语句
第四步 mysqli_num_rows($result) 处理查询结果

联合查询注入

核心四步：

  1. 判断字段数——用 ORDER BY N 测试，直到报错，确定表的最大字段数
  2. 判断回显位——UNION SELECT 1,2,3,... 找到页面显示数据的位置
  3. 信息收集——利用 information_schema 库依次查出数据库名、表名、字段名
  4. 获取敏感数据——用 concat() 拼接多字段，在回显位输出

总结

  1. 数据库层级：库 → 表 → 字段+数据，MySQL 是最常用的开源数据库
  2. CRUD 是核心操作，WHERE 条件不可遗漏
  3. SQL 注入根源是用户输入未过滤，直接拼接到 SQL 语句中
  4. 权限管理遵循最小权限原则，重点加固 root 账号
  5. 日志用于溯源审计，备份是最后一道防线
