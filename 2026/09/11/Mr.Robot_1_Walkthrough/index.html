3.5.3 TTY 交互式升级

报错含义：拿到的反弹shell没有TTY虚拟终端，su、sudo这类命令必须在真实终端环境才能运行。

1. 原理

名词 解释
TTY Unix的虚拟终端。负责：Ctrl+C信号转发、密码输入回显控制、作业控制。没有TTY，su/sudo无法执行。
普通反弹shell IO走socket网线通道，没有TTY设备；直接敲/bin/bash不会生成TTY，环境不变。
python pty pty模块在靶机上创建虚拟TTY设备，把bash挂载到这个虚拟终端上，完成shell升级。

3.7.2 Nmap SUID 提权

原理： SUID 权限，会让程序运行时，继承这个程序文件所有者的身份，而不是当前运行人的身份。

  1. 看 nmap 这个文件的权限

文件所有者是root，所以任何人运行这个 nmap 程序，进程的 euid 都会变成这个文件的属主 root。

  1. 老版本 Nmap ≤4.x 自带 --interactive 交互式模式。

  1. !sh

! 后面跟系统命令，用 nmap 当前进程的身份去执行这条系统命令

!sh = 执行 /bin/sh，弹出一个新的 shell 窗口。

key3：04787ddef27c3dee1ee161b21670b4e4

Q：shell 补充

程序 全称 说明
/bin/sh Bourne Shell 最古老基础 shell，很多系统是软链接到 dash
/bin/bash Bourne Again Shell 我们最常用的，Ubuntu/Kali 默认 shell
/bin/dash Debian Almquist Shell 轻量版 sh，Ubuntu 里 /bin/sh 实际指向 dash
