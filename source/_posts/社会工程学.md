# 一、认识社会工程学
## 1. 核心定义
社会工程学**不是黑客技术、不是代码漏洞攻击**，是利用**人性弱点、心理弱点、贪欲、恐惧、信任、惰性**欺骗目标，诱导对方主动泄露信息、交出权限、执行危险操作的攻击手段。  
核心逻辑：**人是网络安全体系里最大的漏洞**，比起破解密码、入侵服务器，欺骗人成本更低、成功率更高。

## 2. 软安全与硬安全
### 2.1 硬安全（物理安全、硬件安全）
指**看得见、摸得着的实体设备、物理环境防护**，依靠硬件、物理隔离、实体管控实现安全。  
防护对象：机房、服务器、电脑、门禁、U盘、监控、锁具、网线、交换机、设备机身等实体资产。



#### 2.1.1 硬安全措施
1. 物理门禁、刷卡闸机、访客登记、防止尾随（对应物理社工尾随攻击）
2. 机房门锁、保险柜存放服务器/密钥U盘
3. 监控摄像头、红外报警、机房专人值守
4. 硬件加密狗、硬盘加密、硬件防火墙
5. 禁止外来U盘、陌生数据线接入内网设备（防御诱饵攻击Baiting）
6. 设备锁、机箱防盗锁，防止硬件被偷、硬盘被拆走



#### 2.1.2 安全威胁（硬件层面）
尾随蹭门禁、盗取电脑、窃取U盘、物理拆机拷贝数据、投放恶意硬件（窃听充电线）

---

### 2.2 软安全（逻辑安全、人为安全、系统软件安全）
分为两层：**软件系统安全 + 人员/管理安全**  
不靠实体硬件阻挡，依靠代码、策略、制度、人员意识防护。

#### 分支1：软件/系统安全
操作系统、应用软件、网站代码、网络协议、防火墙策略、账号密码、病毒查杀、漏洞修复、加密算法。  
威胁：木马、病毒、Web漏洞、钓鱼链接、恶意附件、网络渗透。

#### 分支2：人员/管理安全
依靠员工安全意识、公司管理制度规避人为漏洞，**社会工程学全部属于软安全范畴**。  
核心：弥补“人”这个最大漏洞，也就是防御心理按钮操纵、各类社工欺骗。

#### 2.2.1 软安全措施
1. 账号密码复杂度、定期改密、二次验证码
2. 员工安全培训，识别钓鱼短信、冒充领导诈骗
3. 财务转账复核制度、陌生信息官方核验制度（防御权威+紧迫心理按钮）
4. 软件定期打补丁、杀毒软件、邮件过滤恶意附件
5. 权限分级，普通员工无服务器高权限
6. 保密制度：社交平台禁止泄露公司信息（防御前期OSINT信息搜集）

#### 2.2.2 安全威胁（软件/人）
钓鱼攻击、冒充领导社工、木马病毒、系统漏洞、弱密码、员工泄密

# 二、底层核心原理：心理按钮
## 1. 定义
心理按钮也叫心理扳机，是社会工程学**底层核心心理学理论**。  
攻击者通过话术、场景、身份刻意触发这套心理机制，让人跳过理性思考，本能顺从对方，主动泄露信息、转账、开放权限。  
内在逻辑：人性弱点是人自带的内在特质，心理按钮是攻击者用来引爆弱点的外部操纵方式。

## 2. 八大心理按钮
1. **权威按钮**  
人本能服从上级、警察、运维、官方人员，主动放下防备。  
例：冒充老板、公安索要账号。
2. **紧迫感按钮**  
制造时间限制，不给思考、核实机会。关键词：立刻、10分钟、超时冻结。
3. **稀缺按钮（FOMO错失恐惧）**  
限量福利、内部名额，害怕损失利益而冲动操作。
4. **互惠按钮**  
先给小好处（资料、福利），使人产生亏欠感，愿意回报对方敏感信息。
5. **好感/熟悉按钮**  
伪装熟人、同行，利用相似感、熟悉感降低警惕。
6. **恐惧按钮**  
用违法、冻结、起诉、设备中毒制造恐慌，逼迫妥协。
7. **好奇心按钮**  
利用人对私密内部文件的好奇，比如标注工资、裁员表的木马U盘。
8. **同情&从众按钮**  
同情：编造困难借钱；从众：所有人都办理，诱导跟风操作。

# 三、常见社会工程攻击手段
## 1. 钓鱼攻击（Phishing）
+ 邮件钓鱼：伪装银行、企业官方，附带恶意链接/恶意附件，诱导输入账号密码。
+ 短信钓鱼（Smishing）：冒充快递、运营商、政务机构，发送带木马链接短信。
+ 语音钓鱼（Vishing）：电话伪装客服、工作人员，套取银行卡、验证码信息。

## 2. 借口伪装（Pretexting） 
编造合理身份、虚构场景骗取信息。

> 例子：伪装IT运维，谎称系统升级索要账号密码；冒充公检法恐吓受害者进行转账。
>

## 3. 尾随 / 蹭门禁（物理社工 Tailgating） 
攻击者紧跟授权员工身后，跟随刷卡混入办公区、机房；伪装访客骗取进入内部区域，窃取硬件、资料。

## 4. 诱饵攻击（Baiting） 
投放带有诱惑的载体植入恶意程序。

> 例子：楼道丢弃标注“财务资料”的U盘，员工插入电脑即中毒；恶意充电线、共享充电宝窃取数据。
>

## 5. 反向社会工程学 + 信息搜集 
前期通过社交平台、企查查、招聘网站收集目标姓名、岗位、同事、生日等信息；掌握大量真实信息后进行精准伪装，提升欺骗成功率。

## 6. 水洞攻击（Watering‑hole） 
攻陷目标群体经常访问的网站（行业站点、内部论坛），植入恶意代码，等待受害者主动访问网站中招。

## 7. 职场施压 / 人情胁迫 
冒充上级领导发送紧急指令，利用层级权威心理，要求私下转账、导出机密资料，禁止走正规流程。

# 四、攻击链
> 社工攻击链完整流程：**信息收集 → 建立信任 → 触发心理按钮 → 诱导执行动作 → 达成目标 → 痕迹清理**
>

## 1. 信息收集（侦察 Recon）
攻击者先搜集目标情报，为后续欺骗做铺垫。

+ 公开渠道：社交平台、企业官网、招聘网站、公开新闻、朋友圈
+ 获取信息：员工姓名、岗位、部门、联系方式、工作习惯、组织架构
+ 垃圾搜寻（Dumpster diving）：翻垃圾桶获取打印废纸、单据、便签密码

> 目的：拿到素材，让伪装显得真实可信。
>

## 2. 建立信任（确定攻击手段）
伪造身份，降低目标警惕。  
伪装身份示例：客服、上级领导、运维工程师、公检法、快递、第三方服务商。  
手段：打电话、钓鱼邮件、微信/QQ、线下上门、短信。  
利用搜集到的信息，说出目标真实信息，让对方认为“自己人”。

## 3. 触发心理按钮（心理操纵，社工核心）
调用人性弱点施压，逼迫/引诱对方快速行动，不给思考时间。  
常见心理按钮：

+ **权威**：我是领导/警察，你必须配合
+ **紧急/稀缺**：马上冻结账号，限时处理
+ **恐惧**：涉嫌违规，否则承担法律责任
+ **互惠/贪婪**：福利、红包、内部资料
+ **同情**：遇到麻烦，请帮忙救急
+ **从众**：其他人都已经提交

> 关键：制造压力，让受害者跳过理性判断。
>

## 4. 诱导执行操作（执行阶段）
欺骗受害者主动做出危险行为，**人主动犯错，不是破解漏洞**。  
典型动作：

+ 泄露密码、验证码、工号、内部文档
+ 点开钓鱼链接、打开恶意附件
+ 插入陌生U盘
+ 转账汇款
+ 开门放行外来人员

## 5. 达成攻击目标
拿到想要的资源：

+ 获取账号权限、敏感数据
+ 获取物理访问权限进入机房
+ 拿到资金、内部机密资料

## 6. 痕迹清除
销毁聊天记录、删除邮件、挂断电话，减少被溯源的线索。

## 📌防御对应
| 攻击链阶段 | 对应防御手段 |
| --- | --- |
| 信息收集 | 管控对外公开信息；敏感纸张碎纸销毁 |
| 建立信任 | 严格访客管理；陌生身份必须二次核验 |
| 心理操纵 | 安全培训，识别心理按钮，拒绝紧急施压下操作 |
| 诱导执行 | MFA多因素认证；不提供验证码密码；外设管控 |
| 达成目标 | 最小权限、双人复核，缩小损失范围 |
| 痕迹清除 | 留存聊天、通话记录，保留证据便于溯源 |


### Q1：MFA多因素认证是什么？
MFA（Multi-Factor Authentication，多因素认证）是一种身份验证机制，要求用户提供两种或两种以上不同类型的验证因素才能登录系统，比单一密码安全得多。

#### 1. 三大验证因素
| 因素类型 | 说明 | 常见例子 |
| --- | --- | --- |
| 你知道的（知识因素） | 只有用户本人知道的信息 | 密码、PIN 码、安全问题 |
| 你拥有的（持有因素） | 用户持有的物理/数字设备 | 手机验证码、U盾、硬件密钥（Yubikey）、身份卡 |
| 你本身的（生物特征） | 用户的生理特征 | 指纹、面部识别、虹膜、声纹 |


**MFA（多因素认证）规则**：至少组合**2种不同类型**的验证因素；密码+手机验证码就是典型双因素认证 2FA。

#### 2. 为什么需要MFA
1. 防范密码泄露被盗：就算密码被钓鱼、泄露，攻击者缺少第二个验证因素，依旧无法登录账号
2. 大幅降低账号被黑风险：微软数据，开启MFA可以阻挡 **99.9%** 的账号爆破攻击

#### 3. 5种常见MFA实现方式
1. **TOTP 时间验证码**（Google Authenticator）：每30秒生成一次性6位数字
2. **短信/邮件验证码**：普及率最高，安全性偏弱；存在SIM卡劫持漏洞风险
3. **推送通知认证**（微软 Authenticator）：手机弹窗一键选择「允许/拒绝」登录
4. **硬件安全密钥**（YubiKey、FIDO2/U2F）：**安全性最高**，自带抗钓鱼能力
5. **生物识别认证**：指纹、人脸

#### 4. MFA核心思想
光知道密码不够，还得证明你**真的是你**。

#### 5. 易混
+ ❌ 密码+安全问题：**不算MFA**，两个都属于【知识因素】，属于同一类
+ ✅ 密码(知识)+手机验证码(持有)：属于合法双因素认证

# 五、防御手段
1. 主机立即断网隔离，禁止重启（保留恶意样本、内存攻击痕迹）；
2. 提取邮件、恶意附件、进程日志溯源钓鱼来源；
3. 重置该主机所有账号密码，排查内网横向移动痕迹；
4. 全网复盘同类钓鱼邮件，同步更新邮件网关拦截规则；
5. 针对中招员工开展一对一社工安全再培训。
